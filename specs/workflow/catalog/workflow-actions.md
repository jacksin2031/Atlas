# WORKFLOW ACTIONS\n\nCatalog document for workflow-actions.\n\nThe workflow-actions catalog document enumerates all workflow action types supported by Atlas. Actions are operations performed by nodes during execution. Each action type declares its inputs, outputs, idempotency properties, and side effects. Actions are registered with the action registry and can be invoked by any node type.\n\n---\n\n## Classification\n\n| Attribute | Value |\n|---|---|\n| Category | Workflow |\n| Type | Catalog |\n| Status | Proposed |\n| Version | 1.0.0 |\n
