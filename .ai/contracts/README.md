# .ai/contracts/

## Purpose

AI Agent contracts — role definitions for the ADS agent system.

These define how each agent role (Architect, Backend, Frontend, Planner,
Reviewer, Vision) interacts with the system. Distinct from `contracts/`
which holds Runtime/IPC/Plugin API contracts.
