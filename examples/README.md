# examples/

## Purpose

Example projects demonstrating Atlas usage patterns. These are reference
implementations, not production code.

## Ownership

Documentation team

## Directory Structure

| Directory    | Demonstrates                        |
| ----------- | ----------------------------------- |
| `minimal/`  | Smallest possible Atlas application |
| `plugin/`   | Custom plugin development           |
| `workflow/` | Workflow pipeline construction      |

## Dependency Rules

- Examples depend on `packages/*` for shared types.
- Examples MUST NOT be imported by production code.
