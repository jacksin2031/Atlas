Title:
Architecture Freeze

Status:
Accepted

Date:
YYYY-MM-DD

Decision

The Atlas repository architecture is now considered stable.

Future development should focus on implementation,
specifications, and engineering standards.

Top-level directory changes require a new ADR.

Context

The repository structure has reached a stable state.

Continually changing the repository layout
would increase maintenance costs and reduce AI reproducibility.

Consequences

Future work should prioritize:

• Specifications

• Core implementation

• Testing

• Documentation

Instead of restructuring the repository.
