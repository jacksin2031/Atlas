# contracts/

## Purpose

Runtime, IPC, and Plugin API contract definitions.

This directory holds interface contracts for the Atlas Runtime system:
- `api/` — Service interface definitions
- `json/` — JSON schema files for validation
- `ipc/` — IPC contract definitions

These are distinct from `.ai/contracts/` which holds AI agent role contracts.
